# Emotion diary - 감정 일기 작성

## 사용자와 목표
- 사용자 : 감정을 포함한 일기를 작성하고 싶은 사람
- 목표 : 날짜, 감정 등을 선택하고 일기를 작성한다.

## 시작 화면
- 메인 화면 메뉴 아래에 있는 "일기 작성" 버튼을 클릭하면 나타나는 팝업

## 핵심 입력
- 날짜
- 선택한 날짜의 감정
- 일기 제목
- 일기 내용

## 결정 또는 선택
- 날짜 버튼(어제, 오늘)
- 감정 이미지

## 완료 상태
- 작성한 일기를 확인하고 일기 저장 버튼을 클릭하면 "일기가 저장되었습니다."라는 alert 출력

## 사용자의 흐름
1. 회원 가입을 한다.
2. 로그인을 하여 사용자를 확인한다.
3. 일기를 작성할 날짜를 선택한다.
4. 해당 일기를 작성한 날의 기분을 선택한다.
5. 일기의 제목을 작성한다.
6. 일기의 내용을 작성한다.
7. 일기의 날짜, 감정, 제목, 내용을 확인하고 일기를 저장한다.

## 인터랙션 시나리오
1. 로그인
- 사용자 행동, 이벤트 의미 : 일기 작성을 위해 아이디와 비밀 번호를 입력하고 로그인 버튼을 누른다.
- 확인 할 조건 : 1) 아이디와 비밀번호가 입력되고, 2) 아이디와 비밀번호가 가입된 회원 정보와 일치한다.
- 조건 충족 : 일기 작성을 위해 날짜를 선택하는 화면으로 이동한다.
- 조건 미충족 : 
    - 1 ) 값이 비어있다면 로그인 버튼이 disabled되어 클릭되지 않는다.
    - 2 ) "아이디 또는 비밀번호가 올바르지 않습니다."을 alert으로 알려준다.

2. 날짜 선택 
- 사용자 행동, 이벤트 의미 : 일기를 작성하고 싶은 날짜를 선택하고 감정 선택 버튼을 누른다.
- 조건 충족 :  감정 선택 화면으로 넘어간다.
- 조건 미충족 : 작성 취소 버튼 클릭 시 일기 작성 팝업을 닫는다.

3. 감정 선택 
- 사용자 행동, 이벤트 의미 : 일기를 작성하는 날에 주로 느꼈던 기분을 클릭한다.
- 조건 충족 :  제목 작성 버튼을 누르면 제목 입력 화면으로 넘어간다.
- 조건 미충족 : 날짜 선택 버튼 클릭 시 날짜 선택 화면으로 이동한다.

4. 제목 입력
- 사용자 행동, 이벤트 의미 : 일기의 제목을 작성하고 일기 내용 버튼을 누른다.
- 확인 할 조건 : 일기 제목이 3~100자 이내인지 확인한다.
- 조건 충족 : 일기 내용을 쓰는 화면으로 이동한다.
- 조건 미충족 : 제목은 3~100자 이내여야 한다는 메시지를 빨간색으로 변경해 오류를 표시하고 제목 입력창으로 focus한다.

5. 내용 입력
- 사용자 행동, 이벤트 의미 : 일기 내용을 작성하고 일기 작성 버튼을 누른다.
- 확인 할 조건 : 일기 내용이 5~1000자 이내인지 확인한다.
- 조건 충족 : 일기 내용을 쓰는 화면으로 이동한다.
- 조건 미충족 : 
    - 5자 미만인 경우 : 일기 내용을 5이상 작성해야 한다는 메시지를 빨간색으로 변경해 오류를 표시한다.
    - 1000자 이상인 경우 : maxlength로 입력을 막는다.

6. 일기 확인
- 사용자 행동, 이벤트 의미 : 일기의 작성 일자, 감정, 제목, 내용을 확인하고 하단에 배치된 버튼을 클릭해 수정하거나 저장한다.
- 일기 내용 버튼 클릭 : 일기 내용 입력 화면으로 돌아가 작성한 내용을 수정한다.
- 일기 저장 버튼 클릭 : 일기가 저장되었다는 메시지를 출력하고 일기 작성 팝업을 닫는다.
