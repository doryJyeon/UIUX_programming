## week4 반응형 수정

### 확인할 문제
800px 이하 화면에서 사진은 너무 크고, 기능 안내, 회원 가입 폼은 폭이 너무 작아보인다.

### 수정한 내용
- viewport 메타 태그를 추가했다.
- 800px 이하 화면에서 메인 이미지에 object-fit: cover를 적용해 이미지가 일정 높이를 넘지 않게했다.
- 기능 카드 목록을 grid로 변경했다.
- 768px 이하에서 메뉴, 카드, 폼이 각각 한 열을 차지하도록 구성했다.


### 달라진점 
태블릿, 모바일 등 작은 화면에서 보아도 콘텐츠 크기가 균일하고 일관성 있어보이게 되었다.

### 확인할 화면 너비
