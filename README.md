# Emotion diary - 감정 일기 작성
테스트 전 확인 사항
- 주요 화면 사이즈는 1200px / 768px / 390px 입니다.
- 프로토타입 구현 상태로 회원가입 기능은 실제로 구현되지 않았습니다.
- 파일을 직접 열어 확인할 경우 로그인 상태 확인이 정상적으로 작동하지 않을 수 있습니다. Live Server 또는 아래 웹페이지를 통해 확인해 주세요.

[[웹페이지 이동](https://doryjyeon.github.io/UIUX_programming/)]

## 9주차 추가 사항
### 추가/수정한 기능
주로 일기 작성 팝업 부분을 개선했습니다.
- 제목 입력 부분에 '날짜를 제목으로 사용하기' 체크 박스를 추가했습니다.
- 제목 입력에 minlength를 추가하고, 허용 길이를 2~50으로 수정했습니다.
- 일기가 작성된 날짜 선택 시 작성 불가 멘트를 추가하고 작성이 불가능하게 했습니다.
- aria-describedby, aria-live, required를 추가하고 안내용, 오류용 멘트 태그를 분리했습니다.
- 입력에 오류가 있는 input, textarea에 border-color를 추가해 문제 있는 부분이 잘보이게했습니다.
- 저장하기 버튼을 분리하고 submit으로 변경했습니다.
- 일기 작성 시 로컬스토리지를 이용해 저장하는 기능을 추가했습니다.

### 확인 순서
1. 메인 페이지에서 '일기 작성 버튼'을 클릭하여 일기 작성용 팝업을 엽니다.
2. 어제, 오늘 버튼을 클릭하거나 아래에 연도-월-일 영역을 클릭하여 일기를 작성할 날짜를 선택합니다.<br>(이미 일기를 작성한 날짜는 다른 날짜를 선택하라는 오류 안내 멘트가 출력됩니다.)<br>선택 후 하단 '감정 선택 버튼'을 클릭합니다.
3. 해당 일자의 기분이 어땠는지 이모지나 글씨 부분을 선택하고, '제목 작성 버튼'을 클릭합니다.
4. '날짜를 제목으로 사용하기' 체크 박스를 클릭하거나 제목을 직접 입력합니다. <br>(2~50자 내로 입력하지 않을 경우 오류 안내 멘트가 출력됩니다.)<br>'일기 내용 버튼'을 클릭합니다.
5. 일기 내용을 5~1000자 내로 작성하고 '일기 작성 버튼'을 클릭합니다.(글자수 미충족 시 오류 안내 멘트가 출력됩니다.)
6. 작성한 내용을 확인하고 '일기 저장 버튼'을 클릭해 로컬스토리지에 저장하거나 '작성 취소 버튼'을 클릭해 작성한 내용을 초기화하고 팝업을 닫습니다.<br>일기 저장 버튼을 클릭하면 입력한 데이터의 유효성을 검사합니다. 모든 조건을 충족하면 로컬스토리지에 일기를 저장하고, 오류가 있는 경우 해당 입력 단계로 이동하여 수정이 필요한 부분을 빨간색 오류 안내 멘트와 함께 표시합니다.

### 일기 작성 시 
[빈 값 제출]
빈 값을 제출하려는 경우 다음으로 이동하는 버튼(혹은 저장 버튼)에 disabled 속성이 해제되지 않아 클릭을 할 수 없습니다.

[잘못된 값 입력]
값이 잘못된 경우 다음 버튼 disabled속성이 해제되지 않아 클릭할 수 없고, 기본 안내 멘트 아래로 어떤 오류가 있는지 표시하는 빨간색 안내 멘트가 추가됩니다.

[조건부 영역 변경]
제목 입력 시 '날짜를 제목으로 사용하기' 체크 박스를 클릭하면 제목 입력용 input 및 하위 안내멘트, 글자수 체크, 오류 멘트를 숨깁니다.
체크 박스 해제 시 숨겼던게 해제됩니다.

[정상 제출(저장하기)]
입력한 데이터에 문제가 없다면 submit으로 제출하고 submit 이벤트에서 로컬스토리지로 저장합니다. 저장이 완료되면 작성한 일기 확인을 위해 마이페이지로 이동합니다.

[작성 취소]
작성 중 팝업을 닫거나, 마지막 작성 내용 확인 시 '작성 취소' 버튼을 클릭하면 입력 내용을 모두 초기화하고 팝업을 닫습니다.
