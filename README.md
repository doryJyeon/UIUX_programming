# Emotion diary - 감정 일기 작성
테스트 전 확인 사항
- 주요 화면 사이즈는 1200px / 768px / 390px 입니다.
- 프로토타입 구현 상태로 회원가입 기능은 실제로 구현되지 않았습니다.
- 파일을 직접 열어 확인할 경우 로그인 상태 확인이 정상적으로 작동하지 않을 수 있습니다. Live Server 또는 아래 웹페이지를 통해 확인해 주세요.

[[웹페이지 이동](https://doryjyeon.github.io/UIUX_programming/)]

## 10주차 변경 내용
### 추가/수정한 기능
- 감정 일기 서비스 설명 아래에 있던 메뉴를 웹페이지 상단으로 이동했습니다.
- 일기 작성 팝업 버튼과 마이페이지 이동 버튼을 메뉴와 같이 상단으로 이동했습니다.
- PC에서는 메뉴가 상단에 배치되고 모바일(900px 이하)에서는 버튼을 이용해 열거나 닫을 수 있습니다.
- nav 내부의 메뉴를 ul과 li를 이용한 목록 구조로 변경했습니다.
- 메뉴를 클릭해서 화면을 이동하거나, 스크롤한 경우 페이지 영역과 맞는 메뉴에 is-current 클래스가 적용됩니다.
- 마이페이지에서 작성한 일기 옆에 감정 선택 select를 추가하여 작성한 일기를 감정별로 필터링할 수 있도록 변경했습니다.
- 필터링된 일기가 몇 개인지 select 옆에 표시되고, 일기가 없는 경우 목록에 작성한 일기가 없다는 문구가 표시됩니다.

### 메뉴별 목적지
main 태그 내 첫 번째 섹션인 감정 일기 서비스 영역을 제외하고 각 section에서 일치하는 h2를 가진 영역으로 이동합니다.
- 서비스소개 - 서비스 소개
- 기능안내 - 기능 안내
- 이용방법 - 이용 방법
- 회원가입 - 회원가입

### 필터 기준
마이페이지 접속 시 감정 필터는 전체로 선택되어 있습니다.
일기 작성 시 표시되었던 감정의 순서와 동일하게 행복-좋음-보통-슬픔-나쁨 순서로 감정을 선택할 수 있습니다.

### 조작 순서
1. index.html 페이지에서 상단의 메뉴를 클릭해 각 메뉴로 이동하거나 화면 스크롤 시 메뉴에 is-current 클래스가 적용되는지 확인합니다.
2. 메뉴를 클릭해 페이지 내에서 이동해보고, 뒤로가기나 새로고침을 하여도 현재 화면 영역과 메뉴 표시가 일치하는지 확인합니다.
3. 모바일(900px 이하) 화면에서 menu 버튼을 클릭해 메뉴를 열거나 닫아보고, 메뉴를 클릭했을 때 메뉴 영역이 닫히고 화면이 이동하는지 확인합니다.
4. 필터링을 확인하기 위해 메뉴 마지막에 있는 마이페이지 버튼을 클릭합니다.
5. 마이페이지에서 작성한 일기 제목 옆에 있는 감정 선택 필터를 변경하며, 선택한 감정에 따라 일기 목록이 필터링되고, 필터링된 일기 개수와 감정 선택 필터 옆에 표시되는 개수가 같은지 확인합니다.
