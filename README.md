## 12주차 
### 수정 내용
- (style.css) :root에 공통 색상 변수를 정의하고 적용했습니다.
- (index.html) 이용 안내 및 자주 묻는 질문(FAQ)을 아코디언 UI를 적용해 추가했습니다.
- (my_page.html) 일기 목록에서 제목 클릭 시 모달 UI를 적용해 일기 내용을 볼 수 있게 변경했습니다.
- 일기 목록의 제목 요소를 버튼으로 변경하고 전체적인 포커스 스타일을 개선했습니다.
- 일기 더미데이터 생성용 페이지를 추가했습니다.
