[[배포된 웹페이지](https://doryjyeon.github.io/UIUX_programming/)]

## 11주차 웹 접근성 개선
### 개선한 요소
- 서비스 소개의 메인 이미지와 기능 안내 이미지에 의미에 맞는 대체 텍스트(alt)를 수정했습니다.
- 기능 안내에서 선택된 탭을 명확하게 구분할 수 있도록 글자 굵기(font-weight)를 변경했습니다.
- 마이페이지의 작성한 일기 영역의 배경색을 변경하여 글자와 배경의 구분이 명확하도록 개선했습니다.
- 스크롤 위치에 따라 브라우저 제목이 변경되도록 수정했습니다.
- 마이페이지에서 감정 필터링 기능을 사용할 때 필터를 초기화할 수 있는 버튼을 추가했습니다.
- 일기 작성 팝업과 AI 피드백 설정 화면에서 화면 전환 및 단계 변경 시 포커스가 적절한 요소로 이동하도록 수정했습니다. 또한 설정 저장 후 알림창을 닫으면 설정 변경 버튼으로 포커스가 돌아오도록 개선했습니다.
- 모바일 메뉴와 팝업의 키보드 조작 및 포커스 이동을 점검하고 개선했습니다.
